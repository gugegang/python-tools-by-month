# Python Tools by Month 🐍

A lightweight and interactive Python terminal tool that recommends the best learning platforms, YouTube channels, and documentation based on your chosen month (1-12).

## About the Project
Learning Python can be overwhelming with hundreds of different websites and tutorials. This tool provides a simple monthly roadmap to guide you step-by-step from beginner syntax to building full-stack applications.

## Monthly Recommendations
- **Month 1:** [Coddy.tech](https://coddy.tech) & [W3Schools](https://www.w3schools.com/python/) (Basic syntax and concepts)
- **Month 2:** [Codedex](https://www.codedex.io) & [Programiz](https://www.programiz.com/python-programming) (Interactive and visual learning)
- **Month 3:** [Bro Code](https://www.youtube.com/@BroCodez) & [Exercism](https://exercism.org) (Video tutorials and mentored exercises)
- **Month 4:** [Codewars](https://www.codewars.com) & [ChatGPT](https://chatgpt.com) (Problem solving and AI debugging)
- **Month 5:** [GitHub](https://github.com), [Real Python](https://realpython.com) & [Programming with Mosh](https://www.youtube.com/@programmingwithmosh) (Best practices and version control)
- **Month 6:** [Boot.dev](https://www.boot.dev) & [W3Schools](https://www.w3schools.com) (Backend foundations)
- **Month 7:** [DataCamp](https://www.datacamp.com), [Real Python](https://realpython.com) & [Bro Code](https://www.youtube.com/@BroCodez) (Data analysis and deeper topics)
- **Month 8:** [LeetCode](https://leetcode.com) & [Automate the Boring Stuff](https://automatetheboringstuff.com) (Algorithms and practical scripts)
- **Month 9:** [freeCodeCamp](https://www.freecodecamp.org) & [Corey Schafer](https://www.youtube.com/@coreyms) (Comprehensive projects and OOP)
- **Month 10:** [Kaggle](https://www.kaggle.com) & [scikit-learn](https://scikit-learn.org) (Data science and machine learning)
- **Month 11:** [FastAPI](https://fastapi.tiangolo.com) & [Real Python](https://realpython.com) (Building backend web APIs)
- **Month 12:** Build a full-stack app or website! (Bring everything together)

## How to Run
1. Make sure you have [Python 3](https://www.python.org/) installed.
2. Clone this repository:
   ```bash
   git clone https://github.com/gugegang/python-tools-by-month.git
   ```
3. Navigate to the project directory:
   ```bash
   cd python-tools-by-month
   ```
4. Run the script:
   ```bash
   python main.py
   ```
5. Enter a number between 1 and 12 to see your recommended resources.
